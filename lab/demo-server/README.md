# demo-server

公司内部知识库查询

> Generated by mcp-sprout: logging, error handling, tests and CI are preconfigured.

## Run

```bash
uv sync            # install dependencies (creates .venv automatically)
uv run demo-server  # start the server on stdio and wait for an MCP client
```

## Connect to Claude Code

Run these two commands from this project root:

```bash
uv sync
claude mcp add demo-server -- uv run --directory "$PWD" demo-server
```

Or open this folder in a host that reads `.mcp.json` — the config is already there.

## Project layout

| File | Purpose |
|---|---|
| `src/demo_server/server.py` | Entry point: logs to stderr only, exception fallback in `main()` |
| `src/demo_server/tools/example.py` | Example tools + docstring convention |
| `tests/test_tools.py` | Unit tests for tool functions (no protocol involved) |
| `.github/workflows/ci.yml` | ruff + pytest on every push |

## Why `mcp<2`?

MCP SDK 2.x renamed `FastMCP` to `MCPServer` and changed APIs while most tutorials
still target 1.x. This project pins 1.x on purpose; upgrade deliberately, not accidentally.
